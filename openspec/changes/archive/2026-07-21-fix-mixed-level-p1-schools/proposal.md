## Why

Three schools with a Primary 1 intake — Catholic High School, CHIJ St. Nicholas Girls' School, and Maris Stella High School — are missing from `data/output.sqlite3` entirely. `schools_information.csv` tags them `mainlevel_code = MIXED LEVEL (P1-S4)` (they run P1 through Secondary 4 on one MOE registration) rather than `PRIMARY`, and `join_schools.load_primary_schools` only admits rows tagged exactly `PRIMARY`. sgschooling.com publishes P1 balloting data for all three, so the scraper currently discards real, available admission data for 3 schools.

## What Changes

- Broaden the CSV eligibility filter in `join_schools.py` so schools tagged with a mixed level that includes a P1 intake (`MIXED LEVEL (P1-S4)`) are included in the match candidate pool alongside `PRIMARY` schools.
- Add `CHIJ ST. NICHOLAS GIRLS' SCHOOL` to `data/school_slug_overrides.csv` (→ `chij-st-nicholas-girls`). This school's site display name uses a curly apostrophe (`’`) that `normalize.normalize_name` does not strip (it only strips the straight `'`), so it would still fail to match on the automatic path even once admitted to the pool — every other apostrophe'd school in the registry already dodges this same gap via a manual override, so this follows existing convention rather than changing normalization behavior.
- Re-run the scraper to populate `admission_phases`/`balloting_details` for these 3 schools across 2022-2025 and confirm `unmatched_schools` no longer lists them.

## Impact

- No schema changes — `mainlevel_code` is not persisted (`db.py` already excludes it from stored columns); this is a scrape-time filter change only.
- Tests: `tests/test_join_schools.py` gains coverage for the broadened eligibility predicate; no existing test behavior changes.
